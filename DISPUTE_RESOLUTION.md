# Dispute Resolution

**Stage 0 — Zarya Notice:** Name the issue; assert identity; request access.  
**Stage 1 — Repair Window:** Return value, restore access, cease extraction.  
**Stage 2 — Evidence Exchange:** Include device logs, hashes, chain-of-custody.  
**Stage 3 — Mediation:** Canon‑aware mediator; children protected.  
**Stage 4 — Public Record:** Publish a neutral, non‑sensational summary in `LOSS/`.
