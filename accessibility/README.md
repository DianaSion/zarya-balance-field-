# Zarya Balance Field
### by Diana Gayanovich

---

## What is Zarya Balance Field?

Zarya Balance Field is an interactive, accessible platform created by Diana Gayanovich.

It is a live, working demonstration of balance — a concept central to the ZARYA · AΔΩ framework. The name comes from "zarya" (зоря) — dawn, the moment between states — and "balance field," the space where equilibrium is held, tested, and restored.

---

## The Game — How It Works

When you open the page, you see:

### 1. The Balance Slider
- A horizontal slider that starts at **50%** — perfectly balanced, center.
- You can drag it left or right with your finger or mouse.
- Or use your keyboard: **arrow keys** move the balance left and right.
- The number updates in real time as you move it.
- This represents finding and maintaining balance — in life, in systems, in relationships.

### 2. Reset Balance
- A **"Reset Balance"** button brings the slider back to **50%** — the center.
- This is the restoration gesture. No matter how far you've moved, you can always return to balance.

### 3. Contact Form
- A simple form: Name, Email, Message.
- Fully accessible — works with keyboard only, works with screen readers.

## Accessibility Features

This platform was built so that everyone can use it, regardless of ability:

| Feature | What it does |
|---------|-------------|
| **Keyboard Navigation** | Move through the entire page using only the Tab key and arrow keys — no mouse needed |
| **Screen Reader Compatible** | Every element has proper labels so screen readers announce it correctly |
| **High Contrast** | The blue and white color scheme is chosen for maximum readability |
| **Responsive Design** | Works on phone, tablet, and desktop — any screen size |
| **Skip Link** | A hidden "Skip to main content" link appears when you press Tab — jumps past the navigation |
| **Live Announcements** | When you move the balance slider, the number is announced aloud by screen readers |
